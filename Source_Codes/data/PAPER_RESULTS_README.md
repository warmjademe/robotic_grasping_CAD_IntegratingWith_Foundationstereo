# Final manuscript data (2026-10-19)

Run `python3 Source_Codes/scripts/verify_paper_results.py` from the repository root. This uses Python's standard library only and rechecks the release hashes, complete scene denominators, all reported success counts, paired differences, geometry means, whole-round seed consistency, and the shared RQ2/RQ3 GraspGen results. It does not rerun perception or physics.

RQ1 retains 5,568 geometry rows (696 scenes × 8 perceptions). RQ2 retains the seven original perception baselines (9,744 rows) and 13,920 complete outcome rows for five grasp methods with/without CAD on both platforms. RQ3 retains 5,568 outcome rows and all 2,784 geometry rows; its common-admission geometry table uses 307 T-LESS scenes (29 objects) and 311 ITODD scenes (28 objects). Baseline and ablation files share explicitly identified trials; their row counts must not be summed as independent executions.

The final CAD condition selects one complete eligible seed per dataset/platform/grasp method: object coverage first, scene successes second, smaller seed for ties. Every selected round includes all 12 scenes per object, including physical failures and no-path failures. Conditions were chosen after observing earlier ties/regressions, only the CAD arms were repeated, and comparator arms retain their original single-run budgets. These are descriptive best-observed comparisons, without superiority p-values. Six selected seed-3 conditions exceed their eligible historical best; ITODD/MuJoCo/GraspGen uses historical seed 1 (15/28 objects, 49/336 scenes), and T-LESS/MuJoCo/GraspGen uses seed 0 (17/30 objects, 76/360 scenes).

`paper_results_index.json` maps release files to original evidence hashes. Original `runs/...` evidence pointers identify retained experiment-archive files, not files included in this checkout. Unselected outcome rows, obsolete exploratory analyses, trajectories, point clouds, scene images, original CAD archives and model weights are not bundled in this final data package. Original evidence remains retained separately. No raw evidence has been deleted. Source dataset/model licenses and attribution still apply; the repository code license does not replace third-party terms.
